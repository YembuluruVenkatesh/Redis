Redis List Commands : Command	Purpose

LPUSH	Insert at beginning
RPUSH	Insert at end
LPOP	Remove first
RPOP	Remove last
LRANGE	Read list
LLEN	Size
LINDEX	Get by index
LTRIM	Keep only last N items

Redis Set Commands : Command	Description

SADD	        Add element
SMEMBERS	Get all values
SISMEMBER	Check if value exists
SCARD	Count elements
SREM	Remove element
SUNION	Union of sets
SINTER	Intersection
SDIFF	Difference

Redis Sorted Sets Commands : Command Purpose
ZADD	Add member
ZINCRBY	Increase score
ZRANGE	Lowest → Highest
ZREVRANGE	Highest → Lowest
ZSCORE	Get score
ZRANK	Rank
ZREVRANK	Reverse Rank
ZREM	Remove
