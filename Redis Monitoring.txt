Interview Explanation
1. Redis Version
----------------
Shows the installed Redis server version.

Example:
7.2.14

Useful for checking compatibility with Spring Data Redis.

------------------------------------------------------------

2. Uptime
---------
Shows how long Redis has been running.

Example:
21 seconds

Higher uptime indicates a stable Redis server.

------------------------------------------------------------

3. Connected Clients
--------------------
Number of active clients currently connected to Redis.

Example:
1

Can include:
- Spring Boot application
- Redis CLI
- Redis Insight

------------------------------------------------------------

4. Used Memory
--------------
Amount of RAM currently used by Redis.

Example:
1007.61 KB

Useful for monitoring memory consumption.

------------------------------------------------------------

5. Total Keys
-------------
Total number of keys currently stored.

Example:
32

Includes:
- Product Cache
- Sessions
- Streams
- Hashes
- Sets
- Lists
- Sorted Sets

------------------------------------------------------------

6. Expired Keys
---------------
Number of keys automatically removed after TTL expiry.

Example:
24

Shows TTL is working correctly.

------------------------------------------------------------

7. Evicted Keys
---------------
Number of keys removed because Redis ran out of memory.

Example:
0

0 is ideal.

High values indicate memory pressure.

------------------------------------------------------------

8. Redis Mode
-------------
Indicates deployment type.

Possible values:

standalone
cluster
sentinel

Current:
standalone

------------------------------------------------------------

9. Role
-------
Shows whether Redis is Master or Replica.

Possible values:

master
slave

Current:
master

------------------------------------------------------------

10. Total Connections
---------------------
Total client connections received since Redis started.

Example:
3

Useful for monitoring application traffic.

------------------------------------------------------------

11. Total Commands Processed
----------------------------
Total Redis commands executed since startup.

Example:
80

Examples:
GET
SET
DEL
EXPIRE
HGET
XADD

------------------------------------------------------------

12. Operations Per Second (Ops/Sec)
-----------------------------------
Current Redis throughput.

Example:
0

When application is idle:
0

Under heavy load:
200
500
1000+

------------------------------------------------------------

13. Cache Hits
--------------
Number of requests successfully served from Redis.

Example:
52

Higher is better.

------------------------------------------------------------

14. Cache Misses
----------------
Number of requests not found in Redis.

Example:
0

Miss means application had to query the database.

------------------------------------------------------------

15. Hit Ratio
-------------
Measures cache efficiency.

Formula:

Hit Ratio =
Hits / (Hits + Misses) × 100

Example:

Hits    = 52
Misses  = 0

Hit Ratio =

52 / (52 + 0)
=
100%

Excellent cache performance.
