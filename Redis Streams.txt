What is Redis Stream : 

Think of Pub/Sub.

Publisher
↓
Subscriber

If subscriber is OFF...

❌ Message Lost

Example

Publisher -----> Redis -----> Subscriber

Subscriber Down

Message Gone Forever

----------------------------------------------------------------------------------

Streams solve this.

Instead of immediately sending,

Redis stores every message.

Publisher

↓

Redis Stream
---------------------
1 Product Created
2 Product Updated
3 Product Deleted
4 Product Created
---------------------

↓

Consumer

Nothing gets lost.

List<MapRecord<String, Object, Object>> records =
        stream.read(
                StreamOffset.create(
                        RedisStreamConstants.PRODUCT_STREAM,
                        ReadOffset.latest()
                )
        );

ReadOffset.latest()   -- Read only the newest messages.

ReadOffset.from("0-0")  -- want to replay everything from the beginning

ReadOffset.lastConsumed() -- Read only the messages that this Consumer Group has NOT processed yet.
